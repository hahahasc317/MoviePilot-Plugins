## 插件列表

### 码率优选（BitrateSelector）v1.1.0

下载前按「种子体积 × 8 ÷ 每集时长之和」估算候选资源码率（Mbps），自动优选高码率资源。

- **候选优选**：批量下载前，同一媒体内集数覆盖相同（或被超集覆盖）且码率领先超过设定比例（默认 15%）的低码率候选会被淘汰；整季包按全季时长估算后同类比较。
- **码率优先洗版**（可选开关）：接管电视剧洗版准入判定，候选估算码率需超过插件按「媒体:季:集」记录的基线 ×（1 + 领先比例）才允许升级；基线随每次下载自动积累，旧规则优先级基线不再参与洗版判定。规则组仍负责资源资格筛选（如只要 4K）。
- **低码率拦截**（可选开关）：单个资源提交下载前，估算码率低于门槛（默认 8 Mbps）时取消下载，可能造成缺集，默认关闭。

无法估算码率（缺集数 / 缺时长 / 非 TMDB 识别）的候选自动回退 MoviePilot 原生判定，不影响正常下载。

## 说明

- 仅支持 MoviePilot V3（`system_version >= 3.0.0`）。
- 「码率优先洗版」通过运行时补丁接管洗版准入函数；MoviePilot 升级后如插件行为异常，重新安装本插件即可重打补丁。
