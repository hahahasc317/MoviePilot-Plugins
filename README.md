## 插件列表

### 码率优选（BitrateSelector）v1.4.5

下载前按「种子体积 × 8 ÷ 每集时长之和」估算候选资源码率（Mbps），自动优选高码率资源。

- **候选优选**：批量下载前，同一媒体内集数覆盖相同（或被超集覆盖）且码率领先超过设定比例（默认 15%）的低码率候选会被淘汰；整季包按全季时长估算后同类比较。
- **码率优先洗版**（可选开关）：接管电视剧洗版准入判定，候选估算码率需超过插件按「媒体:季:集」记录的基线 ×（1 + 领先比例）才允许升级；基线随每次下载自动积累，旧规则优先级基线不再参与洗版判定。规则组仍负责资源资格筛选（如只要 4K）。
- **库内基线播种**（v1.2.0 新增）：开启洗版后自动扫描「媒体库根目录」下 P115StrmHelper 生成的 `-mediainfo.json`，用实测码率为没有基线的剧集补种，每天 07:30 自动补充；避免刚启用时因基线为空选到低于库内现有水平的资源。
- **整包码率放行**（v1.4.0）：核心要求整包规则优先级严格高于每一集，规则同为满分时高码整包永远被拒；开启洗版后，经码率核验确有可提升集的整包放行，实际下载集数仍由核心限定。
- **低码巡检洗版**（可选开关，v1.4.0 重做）：每天 10:30（或发送 `/bitrate_inspect` 立即）扫描媒体库实测低于门槛的集。核心把规则满分的集视为洗版完成、永不再搜，巡检会把这类已有基线的集降为待洗（每轮最多 20 集）再触发订阅搜索，能否替换仍由码率准入把关；48 小时内没洗到更高码则恢复满分并冷却 7 天。只处理开启分集洗版的订阅。
- **低码率拦截**（可选开关）：单个资源提交下载前，估算码率低于门槛（默认 8 Mbps）时取消下载，可能造成缺集，默认关闭。

无法估算码率（缺集数 / 缺时长 / 非 TMDB 识别）的候选自动回退 MoviePilot 原生判定，不影响正常下载。

## 说明

- 仅支持 MoviePilot V3（`system_version >= 3.0.0`）。
- 「码率优先洗版」通过运行时补丁接管洗版准入与整包门槛两个核心函数。插件每次加载（包括 MoviePilot 升级重启后）自动重新替换，并每 30 分钟自检；若升级后函数签名变化，该项补丁不安装、对应功能回退核心原判定并发通知，插件详情页可看补丁状态。

### MP暂存残留修复（MPStageFixer）v1.2.0

检测并修复 115 网盘上 CloudDrive2 / 115网盘Plus 留下的 mp-stage 暂存残留（SHA1 秒传重建），整理完成后定向复查 + 定时全量扫描；可选清理孤儿边车（单轮超 50 个自动刹车）；定时核验 durable 整理待复核任务。定时扫描只在有修复结果或异常时通知，115 限流自动熔断。

### 综艺正片净化（VarietyPurifier）v1.2.0

订阅来源的综艺只要正片：选种阶段先剔除（早于码率优选），下载准入时整包拒收带加更/花絮/纯享等标记的种子，整理入库时逐文件拦截漏网的非正片与 Part 分半文件；手动下载放行。
